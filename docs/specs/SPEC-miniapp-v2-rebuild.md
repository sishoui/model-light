# 模型灯控小程序 v2 · 重构方案

> 状态：**已定稿**（甲方授权「不一致重做、其余按推荐」）。本文只描述「做什么、长什么样」，不含代码。
> 定位：推翻现有 v1 实现，从产品形态上重新设计一版更聚焦的 BLE 灯控小程序。
> 术语沿用 [`GLOSSARY.md`](../../GLOSSARY.md)；本文新引入或改动的概念在 §9 单独标注。

---

## 0. 一句话

一个通过 **BLE 直连** 的微信小程序：把设备 8 个引脚各自编排成「灯组 → 阶段 → 图层 → 灯效」，用色环调色的可编程灯效控制器。**无配网、无场景、无定时**，打开就连、 focused 在「编排 + 调参」这一件事上。

---

## 1. 与 v1 的差异（推翻了什么）

| 维度 | v1（现有） | v2（本方案） |
|---|---|---|
| 页面 | 设备列表 / 设备详情 / 引脚 / 灯组 / 阶段 / 预览 / 场景 / OTA / 我的 | **设备列表 / 设备 / 引脚**（3 页） |
| 选色 | 色板 | **色环** |
| 场景 | 有（scene 页 + 固件 scene_store） | **不做** |
| 定时开关 | 无 | 无（保持） |
| 灯珠划分 | 3D 灯板预览里编排 | **2D 方格矩阵**（见 §4.3） |
| 云端 / 账号 / 备份 | 有（openid + 备份） | **砍掉**（纯本地，设备 NVS 为真源） |
| 3D 预览 | 有（xr-frame） | **砍掉**，只保留 2D 方格矩阵 |
| OTA | 有 | **保留**（灯效库扩展需固件升级，轻量入口） |
| 「我的」页 | 有 | **砍掉**独立页，OTA/关于收进设备页 |

> 设计取向：v2 做**减法**，砍掉 &quot;编排之外的周边&quot;（场景、3D、云端），把主路径「选设备 → 选引脚 → 编灯组」走顺。

## 2. 页面结构（3 页）

```
设备列表页（主页）
   │ 点设备卡片
   ▼
设备页 ── 整体开关 + 8 个引脚卡片（滚动）
   │ 点引脚卡片
   ▼
引脚页 ── 顶部：灯组 tab + 「+」 ／ 内容区：灯组配置
```

页面栈深度固定 3 层，任意配置项最多点穿 3 页到达。

> **OTA 不占主导航**：作为设备页内的轻量功能入口（如设备页顶部「固件升级」），点开是独立子页，不进主结构。主结构始终是 3 页。

## 3. 各页面详细设计

### 3.1 设备列表页（主页）

**空态（无任何设备）**
- 居中：空白占位图（未连接/无设备的插画）
- 占位图下方：主按钮「添加设备」

**有设备态**
- 设备卡片纵向列表
- 列表**末尾追加一张「添加卡片」**（带「+」图标），点击整张卡片 → 添加设备
- 每张设备卡片：
  - 封面图（占位图可换）
  - 设备名称
  - 摘要信息（在线/离线状态；可选：引脚数、灯组数）
  - 点击整卡 → 设备页

**长按设备卡片 → 编辑菜单弹窗**（自底部弹出）
- 重命名
- 更换封面图
- 删除设备（红色，二次确认）

### 3.2 设备页

- **顶部：整体开关**
  - 开：设备正常，下方 8 个引脚卡片可交互
  - 关：**所有引脚卡片变灰**、不可点；设备层所有灯光与控制停止
- **8 个引脚卡片**（固定 8 个，不可增删），纵向滚动
- 每张引脚卡片：
  - 图片（可换）
  - 名称（可改，如「头部」「底座」）
  - 引脚信息：**引脚编号（GPIO0–7）+ 当前状态（关闭 / 点亮 / 闪烁）+ 已划出灯组数**
  - 点击整卡 → 引脚页

**长按引脚卡片 → 编辑菜单弹窗**
- 重命名
- 更换图片
- （点击「进入配置」= 等同于点卡片，进引脚页）

### 3.3 引脚页

**顶部：灯组栏**
- 一排灯组 tab（横向，可滚动），每个 tab = 一个灯组名
- tab 行末尾一个「**+**」按钮：新增灯组（上限 8 个，达上限置灰）
- 点击 tab：切换当前灯组
- **长按 tab → 编辑菜单**：重命名 / 删除灯组
  - 删除时若该灯组占用灯珠，提示「将释放 N 颗灯珠」，二次确认

**内容区：当前灯组的配置**
- 阶段列表（纵向）：每个阶段一张卡片，显示 阶段序号 + 时长 + 图层缩略
  - 点阶段卡片 → 展开/进入该阶段编辑（阶段内配图层与灯效）
- 循环模式设置（灯组级，单选）：不循环 / 最后一步循环 / 全部步骤循环

**阶段内部**（编辑一个阶段时）
- 时长：停留时长（默认 2000 ms）
- 过渡：与上一阶段的过渡（默认「无 / 硬切」）
- 图层：固定两个图层槽
  - 灯效图层（dynamic）：放 1 个灯效，或不放
  - 背景图层（background）：放 1 个灯效，或不放
  - 每个图层点「选择灯效」→ 打开灯效库（§5）
- 叠加预览：按 §4.4 规则实时预览

## 4. 数据模型与核心规则

### 4.1 层级

```
设备 Device
 └─ 引脚 Pin ×8（固定 8 个，编号 0–7，可命名）
     └─ 灯组 Group ×1–8（每引脚默认 1 个，最多 8 个）
         └─ 阶段 Stage ×N（按序播放）
             └─ 图层 Layer ×2（灯效图层 dynamic / 背景图层 background）
                 └─ 灯效 Effect ×1（每图层 0 或 1 个，取自灯效库）
```

- 灯组是**独立循环单位**：每个灯组有自己的时间轴，各循环各的，互不等待。
- 总时长 = 该灯组各阶段时长之和。

### 4.2 灯珠归属（互斥）

- 一个引脚的灯珠（0–length-1）划分给该引脚下的若干灯组。
- **一颗灯珠只能属于一个灯组**，重叠则拒绝保存。
- 未被任何灯组覆盖的灯珠 = 未覆盖像素，渲染为**纯黑（不发光）**。

### 4.3 灯珠划分界面（2D 方格矩阵）

- 每格 = 一颗灯珠，按行铺排（行宽默认 10，可视长度换行）；单引脚最多 100 格（10×10）。
- 格子三态：
  - ⚪ **黑空心** = 空闲（未分配）
  - 🔵 **蓝实心** = 当前灯组已选
  - ⚫ **灰实心** = 被其他灯组占用（不可选）
- 操作：
  - 单击：切换该格归属
  - 长按 + 拖动：框选一片，批量切换

### 4.4 图层叠加规则

- 灯效图层与背景图层**叠加**合成。
- 对每颗灯珠：
  - 灯效图层该珠**有亮度** → 显示灯效图层颜色
  - 灯效图层该珠**熄灭（无亮度）** → 透出背景图层
- 只有一层时，直接展示该层。
- 合成方式为**覆盖式**（动态层逐像素盖背景层）。

## 5. 灯效库（预设 + 可调参数）

- 灯效为**预设**，官方内置一批；后续可**增加**（扩展位图 / 版本协商）。
- 每支灯效带一组**参数**（颜色 / 速度 / 方向 / 幅度…），小程序据此自动生成参数面板。
- 参数类型：`color`（色环选色）、`int`（带范围）、`enum`、`bool`、`speed`。

**初版建议清单（待确认，§8）**

| 层 | id | 名称 | 参数 |
|---|---|---|---|
| 背景 | `bg.solid` | 纯色 | color |
| 背景 | `bg.gradient` | 双色渐变 | colorA, colorB, reverse |
| 背景 | `bg.breath` | 呼吸 | color, periodMs, minLevel(0–100) |
| 背景 | `bg.rainbowLow` | 慢速彩虹 | saturation, brightness, periodMs |
| 动态 | `dy.comet` | 流星拖尾 | color, tailLen, speedMs, reverse |
| 动态 | `dy.scan` | 扫描线 | color, width, speedMs, direction |
| 动态 | `dy.blink` | 闪烁 | color, onMs, offMs |
| 动态 | `dy.rainbowFlow` | 流动彩虹 | saturation, brightness, speedMs |
| 动态 | `dy.sparkle` | 随机闪点 | color, density(0–100), decayMs |
| 动态 | `dy.pulse` | 脉冲扩散 | color, periodMs, width |
| 动态 | `dy.colorWipe` | 颜色擦除 | colorA, colorB, wipeMs, holdMs |

## 6. 选色（色环）

- 所有 `color` 参数统一走**色环选色器**：
  - 色相环（拖动手柄选色相）
  - 饱和度 / 明度 二维面板
  - 十六进制 / RGB 数值输入
  - 常用色预设（可选）
- 选色结果即时的实时预览（若在调参态，走实时通道下发）。

---

## 7. 硬件与连接

- 单引脚灯珠数：**0–100 可调**，默认 30。
- 灯珠型号：不关心（对上层透明）。
- **纯 BLE 直连，无配网**。
- 添加设备流程：**扫描 BLE → 选中设备 → 连接 → 完成 → 回主页并选中新设备**；失败可重试。
- 断连：设备按最后编排**脱机自运行**；小程序重连后可继续编辑。

## 8. 定稿决策（甲方授权「不一致重做、其余按推荐」）

| # | 项 | 决定 | 理由 |
|---|---|---|---|
| 1 | 推翻范围 | 小程序 UI **全重做**；**固件 + BLE 协议复用 v1**；**后端砍掉** | v1 编排模型与 v2 层级一致，协议无需重造 |
| 2 | 云端 / 账号 / 备份 | **砍掉** | 设备 NVS 是真源，重连即可读回；省掉后端/备案/账号 |
| 3 | 3D 预览 | **砍掉**，只留 2D 方格 | 与甲方口述一致；3D 吃主包、复杂度高 |
| 4 | OTA | **保留**（轻量入口） | 「灯效库后续可增加」需固件可升级；v1 OTA 已成熟 |
| 5 | 「我的」页 | **砍掉**独立页 | 无账号/备份后内容为空；OTA/关于收进设备页 |
| 6 | 灯效库清单 | **采用 §5 的 11 支** | 覆盖常用，且与 v1 固件兼容 |

> 结论：v2 = **纯本地 BLE 灯控小程序**，主结构 3 页 + 设备页内挂一个 OTA 子页。

## 9. 术语增量（相对 GLOSSARY）

- **方格矩阵（Cell Matrix）**：灯珠划分的 2D 编辑界面，每格一颗灯珠，三态（空闲/本组/他组）。
- **图层槽（Layer Slot）**：阶段内固定的两个位置（灯效图层 / 背景图层），各容纳 0 或 1 个灯效。
- **循环模式（Loop Mode）**：灯组级播放行为：不循环 / 末步循环 / 全部循环。

> 其余术语沿用 GLOSSARY（编排、引脚、灯组、阶段、层、灯效、帧时钟、硬切/淡入等）。
