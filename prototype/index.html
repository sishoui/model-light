wayfinder UI 原型资产

2~3 套可预览的微信小程序 UI 主题与页面布局 demo/outline
子票 #66（prototype 类型） · 对应实现规格决策 #15 原型输出（ticket #60）与决策 #5 页面结构与 tabBar。仅作为 demo/outline 资产，供评审选择与反馈，不写入 miniprogram 生产代码。

下方共 3 套 方案，点击“预览”可在浏览器中直接查看该主题下的色调、页面布局与导航方式。全部资产位于 prototype/themes/，每套包含可预览演示页 index.html、主题色设计令牌 tokens.json 与布局导航大纲 layout-outline.md。

方案 A · 极光夜空

深色主题 · 适合灯效控制

深蓝/近黑背景与霓虹蓝、紫点缀，深色画布更能突出灯光效果，适合夜间操作场景。

预览方案 A
主题色：#0B0F19 背景 / #131B2B 卡片 / #38BDF8 主色
页面布局：卡片式设备列表 + 抽屉式详情
导航方式：底部自定义 tabBar（home/设备、me/我的）+ wx.navigateTo 链路
方案 B · 极简白

浅色主题 · 极简科技

白/浅灰背景与蓝绿色点缀，信息层级清晰，视觉负担低，适合长时间使用。

预览方案 B
主题色：#FFFFFF 背景 / #F8FAFC 卡片 / #2563EB 主色
页面布局：列表 + 堆叠式详情页
导航方式：底部自定义 tabBar（home/设备、me/我的）+ 分段控制器
方案 C · 深色科技

暗色主题 · 赛博风

几乎纯黑背景与青色/品红高对比点缀，强科技感，突出设备状态与实时数据。

预览方案 C
主题色：#050505 背景 / #0F0F0F 卡片 / #00F0FF 主色
页面布局：网格卡片 + 全屏详情
导航方式：底部自定义 tabBar（home/设备、me/我的）+ 抽屉侧边栏
